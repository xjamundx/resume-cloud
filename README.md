# ResumeCloud

ResumeCloud is a markdown-first resume and cover letter editor built with Next.js.

## Current MVP

- Local-first document storage in the browser
- Up to 25 resumes and 25 cover letters
- Markdown editor with live preview
- Built-in resume themes
- Autosave plus explicit save
- Print and zip download (`.md` + `.html`)

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
